# Swap Prism

Aplicación de personalización local para Rocket League en Windows.

## Descargar

El instalador está en [Releases](https://github.com/damobeixon12/Swap-Prism/releases).
Las instalaciones con canal de actualización configurado avisan cuando se publica una versión estable más reciente. Tus datos y copias de seguridad se conservan.

## Comunidad

[Discord de Swap Prism](https://discord.gg/dXa24Y5HtX).

## Versión 0.28.0

- Tema oscuro consistente aunque Windows use tema claro.
- Preescucha en memoria, separada de Descargar y Mi biblioteca.
- Instalador más pequeño, conservando el catálogo de miniaturas.

Cierra Rocket League antes de aplicar o restaurar una personalización.
