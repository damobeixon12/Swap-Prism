# 0.23.1 — Errno 2 al descargar mapas

El fallo se reprodujo con el motor privado empaquetado. El traceback fallaba
en ssl.SSLContext.__new__, antes de crear la conexión HTTPS: el runtime Python
incluye una carga de codex-rejected-cas.pem junto a ssl.py. PyInstaller empaquetó
el módulo sin ese recurso, causando FileNotFoundError sin nombre de archivo.
No era un ZIP ausente ni un mapa corrupto.

work/build_engine.ps1 incluye ahora el PEM original del runtime si existe,
conservando íntegra su verificación de confianza. No se desactiva TLS ni la
validación del nombre del servidor. La prueba previa de 0.23 verificaba snapshot
congelado pero solo descargaba desde Python de desarrollo: eso no cubría el fallo.

work/frozen_https0231.py prueba expresamente desde el motor congelado tanto el
catálogo HTTPS como descarga ZIP e importación real de Triple Goal. Resultado
work/frozen-https0231.json: ambas operaciones correctas, certificados y hostname
verificados, cero escrituras al juego. Se añade prueba de creación de contexto
HTTPS al instalador para detectar recursos de SSL ausentes en futuras entregas.

Se conservan biblioteca, cola, originales y selecciones. Solo se actualizan exe,
motor privado e instalador canónicos. La compilación Rust 0.23.1 completó.
Instalador comprobado: arranque/codec/contexto HTTPS correctos, sin datos privados.
App canónica reabierta y observada en Workshop con versión 0.23.1.
