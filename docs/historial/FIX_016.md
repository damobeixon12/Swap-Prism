# Swap Prism 0.16

Iconos vectoriales originales para navegación y subcategorías, incluyendo coche
de silueta angular, ruedas, decals, boost, estelas, explosiones, marcos, himnos,
texturas y ajustes. El inicio incluye catálogo, biblioteca, cola y accesos con
iconos, un hero ilustrado y navegación del carrusel sin puntos.

FPS: tipografía proporcional Segoe UI como la app, 13 px, ventana 150x28,
posición superior izquierda. Se conserva la activación del usuario. El
framebuffer tiene 4.076 de 4.200 píxeles completamente transparentes; no hay
fondo opaco en uso normal. El fondo al editar la posición es intencional.

Títulos: PlayerInfo devuelve texto plano; el renderizador LOCAL del marcador
aplica HTML después del estilo nativo. Se conservan los estilos y el layout de
las otras filas. Usuario confirmó el título correcto dentro del juego.

Avatar: se mantiene intacta la textura predeterminada del juego. El logo se
incrusta mediante DefineBitsLossless2 + DefineShape3 en un frame nuevo del sprite
TintedAvatarIcons. Solo el PlayerInfo local o su ID local exacto elige ese frame;
las otras filas ejecutan su método original. Usuario confirmó su logo visible.
La textura compartida de los rivales se comparó byte a byte con el original.
Formato: [Adobe SWF 10](https://www.flashrealtime.com/content/dam/Adobe/en/devnet/swf/pdf/swf_file_format_spec_v10.pdf),
[tags soportados por Scaleform](https://help.autodesk.com/cloudhelp/ENU/Scaleform-Help/scaleform_help/flash_support/controltags.html).

Boostmeter: el PNG instalado conservaba blanco/morado, pero la presentación
seguía tiñéndolo. Se inventariaron todas las definiciones: HUD, CodeLibrary de
GFxShell, ReplayHUD y SpectatorHUD. La versión anterior solo trataba HUD.
Ahora el mismo parche visual se genera para las cuatro copias. Neutraliza
transformaciones del medidor completo y cancela solo colorTransform en los
tweens; no cambia el cálculo del boost ni sus animaciones de consumo.

Se instalaron los cuatro paquetes como una transacción, con los originales
verificados y la capa del perfil conservada. Se mantuvo «6 champ». Usuario
confirmó colores correctos en todo el medidor y consumo del turbo funcionando.
Retirar el medidor incluye los companions registrados; restaurar todo también
los devuelve a sus originales. El instalador no incluye selecciones/backups
privados. Datos y originales anteriores conservados.

BOOM: Air Strike importa Boost_Tests.Materials.Boom_Text_MIC, un material
compartido fuera de su paquete. No se modificó globalmente y no se afirma que
su color esté corregido. Ping/MMR y el resto de funciones siguen fuera del alcance.

Verificación: 26 vistas renderizadas; comprobaciones de guards local/rival,
marcador HTML, capas completas del medidor, cantidad de boost intacta, composición
con el perfil y restauración byte a byte en copias. Informes en work/*016*check.json,
work/avatar-scope-check.json, work/meter-companions-check.json. Ninguna prueba
de fixtures modificó el juego instalado. Las aplicaciones reales se hicieron
solo con Rocket League cerrado; las confirmaciones visuales son del usuario.
72 pruebas de Python y 10 de Rust superadas. El instalador se prueba en una
carpeta temporal, incluyendo arranque y codec privado; se comprueba que no
incluye data/profile, imágenes privadas ni backups.
