# Fake rank · corrección 0.26.1

La aplicación fallaba antes de instalar con «Getter de rango fuera del perfil
verificado». GFX_PlayMenuV4 incluye el opcode de metadatos debug (0xef) en
GetbCompletedPlacementMatches; las dos copias de GFxShell usadas en las pruebas
de 0.26.0 no lo incluían. Se excluye ese metadato de la comparación de forma,
conservándolo byte a byte en el cuerpo. Las validaciones de llamadas, campos,
firma, pila y métodos ajenos siguen activas. No se omiten getters desconocidos.

Se comprobaron los 75 paquetes de interfaz sin errores. La prueba de regresión
ejecuta los 12 getters de PlayMenuV4, tanto para la modalidad seleccionada como
para otra modalidad, y comprueba aplicación/reversión sobre copias. Se conserva
la prueba de los 24 getters de GFxShell. La preparación completa de la selección
pendiente del usuario (1600, GC II, división 1, 2v2) terminó en 60.5 s.

Con Rocket League cerrado se instalaron los 64 paquetes del perfil mediante el
motor congelado y la transacción normal. Hashes verificados y cola consumida;
nombre/avatar/título y capas actuales conservados. Solo se aplicó la selección
pendiente del usuario. Registro: work/installed-rank027-current.json.

El escudo genérico se sustituye por las 23 insignias nativas extraídas de
Startup.upk: GFX_Shared_RankIcons.Icon_SkillGroup0_Large a 22_Large.
El selector también muestra cada insignia. Export, tamaño y hash registrados
en app/assets/ranks/sources.json. No se usan emblemas inventados ni el PNG de
Tracker como fuente: la obtención de ese catálogo por HTTP fue rechazada.

14 pruebas Rust aprobadas e instalador 0.26.1 validado (arranque, codec,
HTTPS y exclusión de datos privados). La presentación runtime se verifica
por separado; instalar y comprobar hashes no demuestra qué muestra el menú.

La primera carga runtime confirmó GC II, pero mostraba 32100 en lugar de 1600.
Se verificó Rankings.convertMMR: round(native * 20 + 100). El getter ahora
devuelve (MMR visual - 100) / 20 con aritmética Number, sin redondear ni añadir
constantes a la piscina del ABC. Las pruebas ejecutan también esa conversión.
CODEC_REVISION=7 fuerza la regeneración de perfiles de revisión6.
